# TaskFlow API — Actividad 3
Instalar con npm install. Crear .env con JWT_SECRET aleatorio (mínimo 32 caracteres). Ejecutar npm start. Puerto 3000 local. npm test comprueba sintaxis; npm run debug inicia el inspector local. Importar la colección Postman y ejecutar en orden; cambiar email para repetir el registro. Las credenciales de la colección son exclusivamente de prueba local. Los tokens duran dos horas. Los archivos JSON se leen y escriben mediante fs.promises; las modificaciones se serializan dentro de un proceso. No publicar .env, usuarios.json ni datos privados. El archivo usuarios.json se crea automáticamente si falta. Proyecto académico de una sola instancia. No requiere MongoDB. Las pruebas HTTP deben ejecutarse después de instalar dependencias.
